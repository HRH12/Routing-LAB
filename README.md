# VLANs, Inter-VLAN Routing, & Static Routing Lab

## Lab Overview
This lab combines multiple networking concepts into a single topology to simulate a real-world small enterprise network. The lab focuses on configuring VLANs, assigning switch ports, implementing inter-VLAN routing, and configuring both static and default routes to achieve full network connectivity.
